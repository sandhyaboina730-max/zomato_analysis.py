# Zomato Restaurant Data Analysis

## Project Overview
This project analyzes Zomato restaurant data using Python to understand restaurant ratings, popular cuisines, location preferences, pricing patterns, and customer reviews.

## Objectives
- Clean and preprocess restaurant data.
- Analyze restaurant ratings and popular cuisines.
- Identify restaurant location hotspots.
- Study the relationship between average cost and ratings.
- Visualize data using charts, heatmaps, and word clouds.
- Provide five business recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud
- Jupyter Notebook / Google Colab

## Project Files
- `zomato_analysis.py` — Python analysis code
- `Zomato_Restaurant_Analysis.ipynb` — Jupyter Notebook
- `zomato_cleaned.csv` — Cleaned dataset, if redistribution is permitted
- `zomato_analysis_report.txt` — Summary report generated by the code

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Place the permitted dataset file in the project directory.
4. Run `zomato_analysis.py` or open the notebook in Google Colab.
5. Review the generated charts and report.

## Expected Outcome
The project provides insights into restaurant ratings, cuisines, location hotspots, pricing patterns, and potential improvements for restaurant discovery platforms.
